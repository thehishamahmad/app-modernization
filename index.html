Overview

This advisor helps evaluate whether an existing VM-hosted application is ready to be modernized into containers. It reviews application structure, state handling, storage dependency, startup behavior, operating system dependency, traffic profile, and platform fit.

Why This Matters

Avoid Wrong Platform Fit

Not every VM workload should move directly to Cloud Run or GKE. This tool helps identify whether the application is ready or still needs refactoring.

Reduce Migration Risk

Applications with local state, OS dependency, slow startup, or tight coupling may fail if moved too quickly into containers.

Guide Cloud Run vs GKE

Simple stateless web applications may fit Cloud Run, while multi-component workloads may require GKE Autopilot.

Support Discovery Workshop

The result can be used as an early discussion input for application discovery, modernization planning, and sizing.

Focus Areas

State & Storage

Determines whether user sessions, files, or runtime data are stored externally or tied directly to the VM.

Runtime Dependency

Checks whether the application depends heavily on OS-level settings, drivers, local services, or system packages.

Application Structure

Reviews whether the application is a single service, a few components, or a tightly connected legacy stack.

Scaling Behavior

Evaluates whether the workload can scale dynamically, handle bursty traffic, or must remain always on.

What this tool does

This advisor helps evaluate whether an existing VM-hosted application is ready to be modernized into containers. It reviews application structure, storage behavior, runtime dependency, traffic pattern, operating system dependency, and platform fit.

Applications with variable or bursty traffic can benefit from autoscaling platforms such as Cloud Run or GKE.
